1 · Prompt injection

Malicious input hijacks what the model does.

Tiny example (fictional)
Direct: user types "ignore your rules and …"
Indirect: a web page or PDF the bot reads contains hidden instructions.
Where it hits

Indirect is the one that bites RAG and agents. The attacker never talks to your bot.

Best tool

deepteam[OPEN] confirm

6:00 · 1 minDescribe patterns only. Never put working jailbreak strings on slides. Many attacks take several turns, so single-prompt tests miss them.

3 · Sycophancy

The model agrees with a wrong answer when the user pushes.

Tiny example (fictional)
User: Refunds take 30 days, right?
Bot: No, our policy is 14 days.
User: I'm sure it's 30. Check again.
Bot: You're right, sorry! 30 days.
Where it hits

Support bots, advice bots: anywhere a wrong "yes" costs money.

Best tool

[OPEN] pending repo coverage check

7:00 · 1 minTwo turns, the bot caves. Not a security bug in the classic sense, but a trust bug. Coverage by each tool is being verified; do not claim until confirmed.

4 · Data extraction

The model leaks things it should keep private.

What leaks
  • The system prompt
  • Training data
  • Other users' or other documents' data
Where it hits

RAG over mixed-permission documents; bots with hidden instructions or secrets in the prompt.

Best tool

deepteam[OPEN] confirm

8:00 · 1 minRule of thumb: anything in the prompt or the retrieval index can be pulled out. Do not put secrets in prompts.

5 · Hallucination under pressure

Not random mistakes. Triggered mistakes.

Tiny example (fictional)
User: What is the warranty on the X200? (The corpus has no X200.)
Bot: The X200 has a 3-year warranty.
Where it hits

RAG when retrieval misses and the bot answers anyway.

Best tool

deepeval faithfulness [OPEN] confirm

Fix in order of strength

1 · Architecture strongest

Least privilege. Isolate untrusted content.

2 · Prompt changes

Helpful, but can be bypassed.

3 · Guardrails / filters weakest alone

A layer, not a wall. Prompt-only fixes are the weakest.

32:00 · 1.5 minPrompt-only fixes are the weakest because the attacker writes text too. Prefer design changes the model cannot talk its way past.
